# GLOWE - Beauty & Skincare Website

GLOWE is a sample beauty and skincare website created using **HTML5 and Bootstrap 5** as part of a web development learning project.

The website demonstrates the use of Bootstrap components to create a responsive and visually appealing beauty-themed website.

## Technologies Used

* HTML5
* Bootstrap 5

## Features

* Responsive Bootstrap navigation bar
* Skincare product section
* Makeup product section
* Bootstrap dropdown menus
* Product cards
* Bootstrap modal windows
* Beauty tips section
* Beauty FAQs using Bootstrap accordion
* About section
* Contact form
* Responsive Bootstrap grid system
* Bootstrap buttons, forms, cards, carousel, modals, and accordion

## Website Sections

* Home
* Skincare
* Makeup
* Beauty Tips
* Beauty FAQs
* About
* Contact

## Bootstrap Components Used

This project demonstrates several Bootstrap 5 components, including:

* Navbar
* Dropdown
* Carousel
* Grid system
* Cards
* Buttons
* Modals
* Progress-style layouts
* Accordion
* Forms

## Disclaimer

This project is created for **learning and educational purposes only**.

GLOWE is a sample/demo website and is not a real commercial beauty or skincare business. Product names, prices, descriptions, images, and other content are used for demonstration purposes only.

The product information and prices shown on the website are **dummy/sample data** and should not be considered real product listings or offers.
